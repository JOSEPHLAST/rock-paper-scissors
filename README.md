# ✊🖐️✌️ ROCK-PAPER-SCISSORS   

## **📌 OVERVIEW**  
This is a simple **Rock-Paper-Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer and see if you can beat the AI in this classic hand game!

## **🚀 FEATURES**  
✅ **Classic Rock-Paper-Scissors Gameplay**  
✅ **Interactive UI** – Click buttons to make your choice  
✅ **Randomized AI Opponent** – The computer makes unpredictable moves   
✅ **Instant Result Display** – See if you **win, lose, or draw**

## **🚀 INSTALLATION AND SETUP**  
### **1️⃣ Clone the Repository**  
git clone https://github.com/JOSEPHLAST/rock-paper-scissors.git   
cd rock-paper-scissors   

### **2️⃣ Open in Browser**
Simply open the index.html file in your browser to start playing.   

## **🎮 HOW TO PLAY**
1️⃣ Choose Rock ✊, Paper 🖐️, or Scissors ✌️ by clicking a button.   
2️⃣ The computer will randomly pick one too.   
3️⃣ The winner is determined by the rules:   
	•	Rock beats Scissors   
	•	Scissors beats Paper   
	•	Paper beats Rock   
4️⃣ The game will display “You Win!”, “You Lose!”, or “It’s a Draw!”
